# AchadinhosPW — site

Site estático do AchadinhosPW (página inicial, Termos de Uso e Política de Privacidade).

Regras deste repositório:
- Repositório público: **nunca** commitar chaves, tokens, senhas, `.env`, IPs ou dados pessoais.
- Segredos (TikTok, Mercado Livre, Supabase) ficam apenas nos secrets do servidor/hospedagem.
- Sem scripts de terceiros, rastreadores ou formulários.
